# AI B2B Supplier Selection Copilot

## Overview
An AI-assisted decision-support project designed to help businesses evaluate and compare potential suppliers using relevant selection criteria.

## Objective
To make B2B supplier selection more structured, transparent, and efficient by organizing supplier information and highlighting trade-offs.

## Key Features
- Supplier evaluation and comparison
- Eligibility and priority assessment
- Supplier recommendations with explanations
- Decision support based on selected criteria

## Technology
- Python
- Google Colab
- Jupyter Notebook

## How to Run
1. Download the `.ipynb` notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Follow the notebook cells in order.
5. Provide the required inputs and run the workflow.

## Limitations
Recommendations depend on the quality of the supplied data and the criteria used. Outputs should support—not replace—business judgment and supplier due diligence.

## Project Status
Working prototype. Further validation, testing, and feature improvements may be added over time.
